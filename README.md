# Landing Page

A responsive landing page built as part of **The Odin Project Foundations curriculum**. This project focuses on recreating a provided design from scratch using HTML and CSS.

## About

The goal of this project is to practice the fundamentals of web development, including structuring a webpage with semantic HTML and creating a clean, responsive layout with CSS.

## Skills Demonstrated

* HTML5
* CSS3
* Flexbox
* CSS layout and positioning
* Typography and colors
* Basic responsive design
* Organizing and structuring a webpage

## Features

* Header with navigation links
* Hero section with a call-to-action
* Information/features section
* Quote/testimonial section
* Call-to-action section
* Footer

## What I Learned

Through this project, I improved my understanding of **Flexbox, CSS layouts, spacing, alignment, and creating webpages based on a visual reference**.
